# Skipstorepush Webapp

Admin web client for Skipstorepush. It talks to the Skipstorepush service over REST.

## Local development

```sh
npm install
npm run dev
```

The Vite app runs on port `4001`. Copy a `.env` with `VITE_BASE_URL` and related client keys before starting.

## Scripts

- `npm run dev` — local server
- `npm run build` — production bundle
- `npm test` — Jest with coverage
- `npm run lint` — ESLint
